# 我的世界私人服务器：3 种开服方式怎么选，几个朋友玩该买多大配置、每月花多少钱

想和朋友玩一个只属于你们的 MC 服，卡住的地方通常不是"会不会敲命令"，而是不知道从哪一步开始花钱。有人直接买了 8 核 16G，结果五个人玩原版，一半资源闲置；也有人用家里淘汰的旧笔记本开服，朋友一进世界就看见"无法连接"。

这篇把顺序理清楚：先判断你要的服务器长什么样，再决定配置，最后才是挑服务商和下单。

## 你要的"私人服务器"，私在哪

"私人"两个字在 MC 里通常指三件事，最好在开服第一天就定好：

- **只让邀请的人进**：`server.properties` 里把 `white-list=true`，然后往 `whitelist.json` 加 ID。比设置复杂密码靠谱得多。
- **IP 不主动外传**：公开服会被扫描，私人服只要地址不外流，被 DDoS 或者被陌生人刷资源的概率立刻下降。
- **想不想用盗版客户端联机**：正版验证对应 `online-mode=true`；改成 `false` 之后，离线版客户端也能进，但任何人都可以用你的 ID 冒充进来。朋友之间玩得舒服、图省事的，多半会关掉它——明白风险再关就行。

这里有个绕不开的现实问题：现在家庭宽带基本拿不到公网 IPv4，用自己电脑开服，朋友在外面根本连不上，得靠内网穿透。穿透能用，但延迟和数据稳定性看运气。这也是大部分人会走到"租一台服务器"这一步的原因。

## 配置别瞎猜：MC 吃单核，内存看人数和模组

Minecraft 的服务端主循环是单线程的——怪物 AI、方块更新、红石、玩家操作都在同一条线上跑，服务器目标是每秒 20 tick，也就是说这一个线程只有 50 毫秒处理完一次循环。所以**四核低频的机器跑不过双核高频的机器**，这是 MC 开服选配置最反直觉、也最重要的一条。

内存则是另一套算法。社区里比较通用的经验值：

- 服务端本身占用大约 1–1.5G
- 每个在线玩家额外 200–400MB
- 每个模组再吃 50–200MB（有些重型模组远不止）

插件服还要加：大致每三个插件留 1G 内存的余量。

按这个算，常见场景大致是：

| 玩法 | 人数 | 建议配置 | 给 JVM 的内存 |
| --- | --- | --- | --- |
| 原版 / Paper 纯净服 | 2–5 人 | 2 核 4G | 2–3G |
| 纯净 + 少量插件 | 6–10 人 | 4 核 8G | 5–6G |
| 中型整合包（30–80 mod） | 5–10 人 | 4 核 8G 起，偏紧就上 16G | 6–8G |
| 大型整合包（100+ mod） | 10 人以上 | 8 核 16G 以上 | 10G 以上 |

版本也有影响：1.18 以后的资源消耗大致是 1.16 时代的两倍、1.12.2 的三倍。同一个配置在 1.12.2 上轻轻松松，换到 1.21 加一堆模组就可能顶不住。服务端视距（`view-distance`）从 10 降到 6，性能收益立竿见影，代价是远处地形加载得晚一点。

Java 版本别搞错，这是新手最容易卡住的一步：

- 1.12 以上、1.17 以下：Java 8
- 1.17 以上、1.18 以下：Java 16
- 1.18 以上、1.20.5 以下：Java 17
- 1.20.5 及以上：Java 21

服务端核心的选择也简单：纯净加插件用 Paper，Forge 模组用 Forge，轻量模组用 Fabric。Mohist、CatServer 这类"插件模组都能装"的混合端，报错多、兼容性差，不建议新手第一个服就上。

## 三种开服方式，对号入座

| 路子 | 优点 | 代价 | 适合谁 |
| --- | --- | --- | --- |
| 家里电脑 / 旧机器 | 前期不花钱 | 没公网 IP 要穿透；电脑关机服就停；电费和噪音 | 两三个人偶尔玩、纯测试 |
| 面板服（网页一键开服） | 全程网页操作，支持一键开服、可视化管理、SFTP；常用核心自带 | 自由度不如完整系统，多开和自定义环境受限 | 新手服主、只开一个服 |
| 游戏云 VPS | 完整 Linux/Windows 系统，可多开、可装任何东西、可开放自定义端口、支持备份 | 要自己装环境、配端口 | 长期运营、要装模组或第二个服 |

如果你只是想今晚就和朋友进去种田，面板服更省事；如果打算把这个服养一年、中途还想换个整合包再开个基岩服，VPS 更划算。

## 计费方式选错，等于白省钱

雨云的固定计费和动态计费，是这套产品里最容易被忽略但影响最大的一项。

- **固定计费**：传统月租，机器 7×24 一直跑。每天玩超过 2 小时、或者有人在深夜挂机刷怪的，选它。
- **动态计费**：基础月租很低，然后按每天的 CPU 实际消耗结算"CPU 电费"。低于 20% 使用率不计费，超出部分才算。周末才开黑的服，用这个能省不少。

> 动态计费计的是上一天的 CPU 消耗，账户里记得留余额，余额不够会停机。

## 从下单到朋友进服，完整流程

1. **注册并领券**：新用户注册后绑定微信，可以拿到首月 5 折券。👉 [注册入口在这里，注册后先领券再下单](https://www.rainyun.com/MzA2MTc2_)
2. **选购**：在游戏云购买页依次选产品形态（VPS / 雨云面板 / MCSM 面板）、CPU 机型、区域、计费模式、配置、公网 IP 类型和系统。不确定性能，可以 1 元试用一天。
3. **装环境**：VPS 先把 Java 装到对应版本；面板服直接在面板里选服务端类型。
4. **配端口映射**：NAT 机型要开三条内网端口——25565 给 MC，23333 和 24444 给 MCSM 面板。
5. **上传服务端**：把 Paper / Forge / Fabric 的 jar 传进目录，改启动脚本里的文件名。
6. **同意 EULA**：启动一次后会生成 `eula.txt`，把 `false` 改成 `true`，否则服会立刻退出。这一步拦住的人比想象中多。
7. **调 server.properties**：`online-mode`、`max-players`、`view-distance`、`white-list` 是最该先看的四项。
8. **开机并把地址发给朋友**：格式是 `对外地址:端口`。面板服的地址和控制台里给出的对外地址一致。

## 几个常被问到的问题

**四五个人玩原版，需要 4 核 8G 吗？**
不需要。2 核 4G 足够，重点是内存别卡在 1G 堆——起步就给 2G 以上。真有卡顿，先降视距，再考虑升配置。

**家里电脑能开吗？**
能，但要有公网 IP 或内网穿透，而且电脑一关服就停。想 24 小时在线，云端更省心。

**面板服和 VPS 的差别到底在哪？**
面板服全程网页操作、上手快、适合单端；VPS 给你一台完整机器，能多开、能装任何程序、能自己排错。第一次开服选面板，第二次多半会想换 VPS。

**离线版客户端怎么进来？**
把 `online-mode` 改成 `false`，但务必配好白名单，否则任何人只要知道地址和你的 ID 就能进来。

**能换配置吗？**
可以，CPU、内存、容量都支持弹性升降，面板产品甚至能在线切换 CPU 机型。这也是先从小配置起步的底气。👉 [想直接按机型挑一台，进游戏云购买页选就行](https://www.rainyun.com/MzA2MTc2_)

开私人服这件事，本质上只有两个决策：玩什么版本和模组、几个人在线。把这两个数算清楚，配置和预算基本就定死了，剩下的都是点几下按钮的事。
